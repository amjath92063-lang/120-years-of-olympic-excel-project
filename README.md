# 🏅 120 Years of Olympic History – Excel Data Analysis Dashboard

## 📊 Project Overview

This project analyzes **120 Years of Olympic History** using Microsoft Excel.

The project uses the **athlete_events.csv** dataset to explore Olympic participation, medals, countries, sports, seasons, cities, and athlete-related information.

The data was cleaned and transformed before creating PivotTables, charts, slicers, KPI cards, and interactive dashboards.

## 🎯 Project Objectives

- Analyze Olympic medal performance by country
- Identify the top countries by total medals
- Analyze medals by sport
- Compare **Summer vs Winter** Olympic medals
- Analyze Gold, Silver, and Bronze medal distribution
- Explore Olympic performance using filters and slicers
- Present the analysis through interactive Excel dashboards

## 🛠️ Tools Used

- **Microsoft Excel**
- **Power Query** – Data cleaning and transformation
- **PivotTables** – Data analysis and summaries
- **PivotCharts** – Data visualization
- **Slicers** – Interactive filtering
- **Excel Dashboard** – Final presentation

## 🧹 Data Cleaning

The dataset was cleaned using Power Query.

Main cleaning steps included:

- Handling missing values
- Replacing blank medal values with **No Medal**
- Checking and correcting data types
- Handling errors in Age, Height, and Weight
- Standardizing text and numerical columns
- Preparing the cleaned dataset for analysis
